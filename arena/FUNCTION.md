# 五子棋：只写一个落子函数

1. 安装 Python 3.12，把练习包全部解压。无需安装额外依赖。
2. 双击 START.bat，先运行原版示例；浏览器自动打开练习报告。
3. 用编辑器打开 agent.py，修改后重新试跑。
4. 回网站只上传 agent.py，等待服务器排队评测，之后查看棋谱。

## 输入与输出
`choose_move(board)` 输入15×15二维列表；1是自己，-1是对手，0是空位。
平台已转换执黑/执白视角，你永远是1。返回 `(row, col)`；行列从0到14。
(0,0)是左上角，(7,7)是中心。不能落在已有棋子的地方。
每次调用应根据当前棋盘独立决策，不依赖上一次调用或对局的全局变量。
可在agent.py中写辅助函数和参数。不交ZIP、JSON、权重文件或本地报告。

## 三步练习
- 入门：理解“自己能赢先赢，对方能赢先堵”，先不修改其他逻辑。
- 改进：只改DEFENSE防守权重，记录预期、实际结果和失败棋形。
- 进阶：加入活三/冲四/双威胁识别、候选点筛选或限时搜索。

网站提供规则、教师对手、开局、交换黑白、限时裁判、计分和棋谱。
示例约60行，教学用，不保证战胜教师。无需为了凑行数增加代码。
本地练习对手很简单，不是正式教师基线，本地胜率不能当作正式成绩。
本地计时只能在函数返回后检查；若写出死循环，用Ctrl+C停止。
正式比赛使用隔离评测机强制限时；规则15×15，无禁手，连续五子及以上获胜。
网页展示本场每步时限。超时、非法落子或执行失败由裁判处理。
修改本地competition.json不会改变正式比赛规则。
可使用Python标准库；不要联网、读取其他文件或打印到标准输出。
仅运行本人编写或教师提供的可信代码。声明参考来源与协作内容，保留实验记录。

## 可选进阶：固定神经网络（仍只交agent.py）
基础版无需模型。希望学习神经网络辅助决策时，双击ENABLE_MODEL.bat。
它会准备独立.venv环境、安装依赖、验证模型，成功后备份原agent.py并启用进阶示例。
首次准备需要联网；模型文件已在练习包中，无需另找权重。
之后双击START.bat测试，最后仍只上传agent.py。

```python
from gomoku_model import evaluate
value, policy = evaluate(board)
```
- 输入与choose_move相同：15×15二维整数列表，1自己、-1对手、0空位。
- value：[-1,1]的己方局面估计，越大越有利，但不是校准后的胜率。
- policy：15×15非负落子偏好，已有棋子的位置为0；有空位时总和约为1。
- evaluate不修改棋盘，只做一次模型推理，不包含搜索，也不等于完整“化神”。
- 模型在导入时加载；每步的推理和搜索计入本场时限。调用越多，耗时越多。
- 平台与本场练习包使用同一份冻结模型。修改本地模型不会改变服务器模型。
- 不上传gomoku_model.py、runner.py、ONNX、.venv或competition.json。

进阶示例仍先处理“一步取胜/必须防守”，再融合规则评分与模型偏好。
先只改MODEL_WEIGHT比较棋谱；再考虑候选点筛选、向前搜索。不要把整个网络权重抄进函数。

## 常见错误
- 返回值须是两个整数，例如return 7,7；不要返回225维评分、字符串或一个编号。
- 行列从0开始；不要把(15,15)作为右下角，右下角是(14,14)。
- 已占位置不可落子；检查board[row][col]==0。
- 正式每步时限见网页；本地机器速度不同，本地通过不保证正式不超时。
- 本地报错会显示在终端；死循环用Ctrl+C停止。START不会把本地报告上传。
